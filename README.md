# 🏨 Hotel Management & Reservation System

A responsive and feature-rich web application designed to streamline hotel operations, room reservations, and guest management.

### ✨ Key Features
- **Room Browsing & Filtering:** Explore available rooms by type, pricing, and amenities.
- **Reservation Workflow:** Interactive booking and date selection interface.
- **Admin Dashboard:** Overview of bookings, guest statuses, and room availability.
- **Responsive UI:** Clean, mobile-friendly design optimized for guest and staff usage.
